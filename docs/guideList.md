# Guides

Pick a task, follow a short walkthrough, and check the [command reference](commandList.md) for every option.

| Start here | What you’ll learn |
|---|---|
| [Slash commands](guides/slash.md) | Find Kifo Clanker in Discord’s picker, choose inputs, and use `/help`. |
| [Context menus](guides/contextmenus.md) | Save a message, detect its language, or inspect a member. |
| [Reaction contests and giveaways](guides/contests.md) | Rank posts, handle ties, and choose random winners. |
| [Roles and channel permissions](guides/management.md) | Make temporary changes and create reaction menus. |
| [Automatic threads](guides/autothreading.md) | Turn new posts into discussions with useful title templates. |
| [Creating a ticket](guides/ticket.md) | Ask a clear question in a public or private thread. |
| [Setting up ticketing](guides/ticketing.md) | Configure ticket visibility, archiving, slowmode, and permissions. |
| [Dates and timestamps](guides/epoch.md) | Convert ISO dates or relative durations into Discord timestamps. |

Need help with your own setup? Visit the [support server](https://discord.gg/HxUFQCxPFp). Bot operators can use the [deployment and migration guide](MIGRATION.md).
