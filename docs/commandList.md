# Command reference

Generated by `npm run generate-docs` from the slash-only command registry.

Chat commands using !kifo or custom prefixes are disabled.

## Application commands

### /ping

...pong?

- `reply`: What do you want me to reply with?

### /reverse

This command reverses anything you type.

- `text`: The text to reverse
- `silent`: Whether to show the result to only you, or everyone. False by default.

### /epoch

Easily convert dates to epoch and vice versa.

- `date_to_epoch`: Convert from date to epoch number (in seconds).
- `epoch_to_date`: Convert from epoch number (in seconds) to date.
- `help`: Receive a link to the guide for this command.

### /ticketing

Set up ticketing in this channel.

- `on`: Enable tickets.
- `off`: Disable tickets.
- `list`: List configured channels.
- `help`: Read the ticketing guide.

### /ticket

Create a ticket.

- `title`: Your question or problem.
- `description`: Additional details.

### /autothreading

Set up automatic threads.

- `on`: Enable automatic threads.
- `off`: Disable automatic threads.
- `list`: List configured channels.
- `help`: Read the title template guide.

### /threads

Manage threads in this channel.

- `archive`: Archive oldest active threads.
- `delete`: Delete oldest threads.

### /react

Configure automatic reactions.

- `on`: Enable automatic reactions in this channel.
- `off`: Disable automatic reactions.
- `status`: Show reactions configured in this channel.
- `list`: List automatic reactions in this server.

### /superslow

Configure long message cooldowns.

- `set`: Set the cooldown in this channel.
- `off`: Disable cooldowns and clear their history.
- `status`: Show the cooldown in this channel.
- `list`: List cooldowns in this server.

### /clean

Delete empty permission overwrites in channels or categories.

- `channel`: Channel or category to clean; defaults to this channel.
- `all`: Clean every channel in the server; requires Administrator.

### /perms

Inspect or change channel permission overwrites.

- `info`: Show permission aliases and check your management permissions.
- `report`: Export channel overwrites, optionally for a member or role.
- `set`: Allow, deny, or inherit a permission for selected members or roles.

### /remove

Remove a member role permanently or for a chosen duration.

- `member`: Member whose role should be removed.
- `role`: Role to remove.
- `duration`: Restore after this duration, for example 10m or 2d.

### /menu

Create or revert reaction role and permission menus.

- `help`: Show menu usage and permission aliases.
- `list`: List configured reaction menus.
- `role`: Create a reaction menu assigning a role.
- `permission`: Create a reaction menu granting a channel permission.
- `revert`: Revert a menu and restore captured participant states.

### /list

Export members or roles to a text attachment.

- `server`: Export all server members.
- `user`: Export a member’s roles; defaults to yourself.
- `roles`: Export members having every specified role, optionally in a channel.

### /stats

Show server, member/bot, or role statistics.

- `member`: Member whose statistics to show.
- `role`: Role whose statistics to show; choose either member or role.

### /top

Rank unique authors by a reaction in a channel over a time period.

- `winners`: Number of winning posts, including ties at the cutoff.
- `duration`: Time period between 10s and 14d.
- `channel`: Channel to scan; cross-channel results are sent by DM.
- `emoji`: Unicode emoji, custom emoji, or custom emoji ID.

### /lang

Detect a message’s language.

- `message`: Discord message ID or link.

### /prefix

Learn how to use the bot’s native slash commands.

### /todo

Send yourself a pinned to-do note in DMs.

- `text`: Your task description.
- `link`: Discord message link to include in the note.

### /test

Test out if slash commands work properly.

- `input`: The text to return.
- `input2`: The text to return.
- `arguments`: Show how whitespace-separated arguments are parsed.

### /guide

Receive a guide link for a specific topic.

- `choice`: Select a topic to learn about.

### /bookmark

Save a message and its attachments in your DMs.

- `message`: ID or URL of the message.
- `pin`: Pin the saved message. False by default.

### /error

Report a bot problem as a GitHub issue. Do not spam.

- `description`: Describe how and when the error occurred.

### /urmum

Random yo momma joke.

### /poll

Create a poll.

- `question`: Ask the question or an opinion.
- `timeout`: When to calculate results? Use "0" for no timeout.
- `one`: Option 1
- `two`: Option 2
- `three`: Option 3
- `four`: Option 4
- `five`: Option 5
- `six`: Option 6
- `seven`: Option 7
- `eight`: Option 8
- `nine`: Option 9
- `ten`: Option 10

### /countdown

Count down to a given time, then show your message.

- `epoch`: Unix seconds; use /epoch date_to_epoch to get the number.
- `message`: The message to show when the countdown ends.

### /giveaway

Choose random winners from users who react before a deadline.

- `winners`: Number of distinct winners.
- `duration`: Duration of at least 1 minute, for example 1h.
- `emoji`: Entry reaction, such as ✅ or a custom emoji.

### /reload

Bot owner only: Reload cached settings.

### /serverlist

Bot owner only: List connected servers.

### /cmdlist

Bot owner only: List registered commands.

### /deploy

Bot owner only: Review and confirm command registration/removal.

- `operation`: Registration or removal scope.

### /help

List slash commands or show command details.

- `command`: The command to describe.
- `category`: List commands in a category.
