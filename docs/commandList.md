# Command reference

Generated by `npm run generate-docs` from the command registry.

## Prefix commands

### react

Configure automatic reactions: on <emojis>, off, list, or status.

- react on <emojis>
- react off
- react list
- react

### superslow

Configure cooldowns from 6h to 1y; 0s disables. Use list or no arguments for status.

- superslow <6h–1y>
- superslow 0s
- superslow list
- superslow

### clean

Delete empty permission overwrites in this channel, a channel/category, or all channels: clean [channel|category|all].

- clean [channel|category|all]

### perms

Inspect or change channel overwrites: perms [here|list|channel|member|role], perms <add|rm|deny> <permission> <member/role>... [duration].

- perms [here|list|channel|member|role]
- perms <add|rm|deny> <permission> <member/role>... [duration]

### remove

Remove a member role permanently or temporarily: remove <member> <role> [duration].

- remove <member> <role> [duration]

### menu

Create, list, or revert reaction role and permission menus.

- menu
- menu list
- menu role <role> [duration]
- menu perm <permission> <channel> [duration]
- menu revert <message ID or URL>

### list

Export server members, a member’s roles, or members with all roles; optionally filter by channel/here.

- list
- list <member ID/mention or me>
- list [channel/here] <role> [role ...]

### stats

Show detailed server, member/bot, or role statistics. Use stats me for your statistics.

- stats
- stats <member ID/mention, role ID/mention, or me>

### top

Rank 1–10 unique authors by a reaction in a channel over 10s–14d; requires Manage Channels.

- top <1–10 posts> <10s–14d> <channel> <reaction>

### lang

Detect the language of a message using Detect Language.

- lang <message ID or Discord link>

### prefix

Receive details about supporting the bot and requesting a custom server prefix.

- prefix

### todo

Send yourself a pinned to-do note in DMs. React to the note to delete it.

- todo <description>
- todo <Discord message link> [description]

### test

Show how your arguments were parsed.

- test <args>

### giveaway

Choose random winners from users who react before a deadline.

- giveaway <winners> <duration> [emoji]

### reload

Reload cached configuration after operator database changes.

Bot owner only.

### serverlist

List the servers this bot has joined.

Bot owner only.

### cmdlist

List deployed application commands in this server and globally.

Bot owner only.

### deploy

Review and confirm application command registration or removal.

- deploy — choose this server, global registration, or removal, then confirm

Bot owner only.

### help

List categories, commands, and detailed usage.

- help [category|command]
- <command> help

## Application commands

### /ping

...pong?

- `reply`: What do you want me to reply with?

### /reverse

This command reverses anything you type.

- `text`: The text to reverse
- `silent`: Whether to show the result to only you, or everyone. False by default.

### /epoch

Easily convert dates to epoch and vice versa.

- `date_to_epoch`: Convert from date to epoch number (in seconds).
- `epoch_to_date`: Convert from epoch number (in seconds) to date.
- `help`: Receive a link to the guide for this command.

### /ticketing

Set up ticketing in this channel.

- `on`: Enable tickets.
- `off`: Disable tickets.
- `list`: List configured channels.
- `help`: Read the ticketing guide.

### /ticket

Create a ticket.

- `title`: Your question or problem.
- `description`: Additional details.

### /autothreading

Set up automatic threads.

- `on`: Enable automatic threads.
- `off`: Disable automatic threads.
- `list`: List configured channels.
- `help`: Read the title template guide.

### /threads

Manage threads in this channel.

- `archive`: Archive oldest active threads.
- `delete`: Delete oldest threads.

- `two`: Option 2
- `three`: Option 3
- `four`: Option 4
- `five`: Option 5
- `six`: Option 6
- `seven`: Option 7
- `eight`: Option 8
- `nine`: Option 9

### /countdown

Count down to a given time, then show your message.

- `epoch`: Unix seconds; use /epoch date_to_epoch to get the number.
- `message`: The message to show when the countdown ends.
